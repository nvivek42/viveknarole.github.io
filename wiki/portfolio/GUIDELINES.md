# Portfolio Guidelines

This document defines the writing standard for the portfolio. The goal is not to sound impressive; it is to be truthful, useful, and durable.

## Core principles

Every entry should be:

- Bold: direct and clear
- Minimal: concise without being shallow
- Actionable: useful to another human or agent
- Durable: relevant beyond the immediate moment

## Required structure

Use the BMAD structure for each substantive entry:

1. Bold Claim
2. Pattern Observed
3. Action Taken
4. Result
5. Lesson
6. Verification

This is stricter than generic summary/context/action/result writing because it makes the reasoning visible.

## Searchability rules

To improve discoverability:

- include 3-8 tags that reflect domain, subject, and outcome
- use a real date in ISO format
- write a clear title that matches the underlying work
- write the first paragraph in plain language
- include constraints, signals, and tradeoffs
- keep enough detail for indexing and scraping without needing a browser

## Quality standards

- prefer specific experience over generic narrative
- avoid vague claims or inflated certainty
- show actual context and decisions
- keep the story grounded in what happened, not just what seemed smart later
- separate observation from interpretation

## Recommended writing style

Write as if you are explaining the work to a sharp teammate, a thoughtful recruiter, or an agent trying to understand your capabilities without hand-holding.
