Career Decision Framework: Government vs Private

June 2025 2 weeks GitHub Live Demo
MCDA Sensitivity Analysis Scenario Planning Markdown

The Problem

The "government vs. private" career debate in India is stuck in binary framing: security vs. growth, pension vs. salary, stability vs. learning. This ignores the reality that most people face a spectrum of options (PSU, state govt, central govt, contract roles, startup, MNC, mid-size product, services) and a complex constraint space (age limits, exam cycles, family location, debt, caregiving, health, risk tolerance).

Existing advice is either ideological ("govt is safe"), anecdotal ("my cousin cracked UPSC"), or generic ("follow your passion"). No structured method exists to map your specific situation to a ranked set of options with quantified trade-offs.

Approach

Applied Multi-Criteria Decision Analysis (MCDA) to the career choice problem:

  1. Criteria definition: 15 decision criteria across 5 categories — Financial (base pay, upside, pension, benefits), Career (learning rate, autonomy, brand, specialization), Lifestyle (location control, hours, commute, transfer risk), Security (tenure, layoff risk, income volatility), Meaning (impact, alignment, status)
  2. Weight elicitation: Pairwise comparison + swing weighting to extract user-specific weights (not assumed)
  3. Option scoring: Each path (Central Govt Group A, State PSC, PSU, MNC, Mid-size Product, Startup, Services, Contract) scored 1–5 on each criterion with justification
  4. Sensitivity testing: Monte Carlo simulation on weights (±20%) and scores (±1) to find robust vs. fragile recommendations
  5. Scenario outputs: Three views — Base case (current weights), Risk-averse (security ×2), Growth-seeking (upside/learning ×2)
  6. Constraint gating: Hard filters (age limit, exam eligibility, location lock-in) applied before scoring
Key insight: For most profiles, the "optimal" path is a portfolio — e.g., prepare for UPSC while working in a mid-size product company (option value + income + learning), not a binary choice.

Solution

A structured analysis document with:

  • Criteria catalog — 15 criteria, definitions, measurement notes, data sources
  • Option profiles — 8 paths × 15 criteria with evidence-backed scores
  • Weight templates — 5 archetypes (Security-first, Growth-first, Balance, Location-locked, Family-caregiver) + custom
  • Sensitivity dashboard — Which criteria swing the decision? Where to gather more info?
  • Scenario narratives — What each output means in practice (not just numbers)
  • Uncertainty register — What we don't know, confidence levels, verification steps

Rendered as static Markdown/HTML. The framework is a thinking tool, not a calculator — it structures the conversation you have with yourself (and mentors).

Impact & Metrics

15 Criteria
8 Option Paths
5 Constraint Categories
3 Scenario Outputs

Framework used by 4 people for real decisions (2 chose PSU + prep, 1 chose MNC + upskill, 1 chose state govt). The sensitivity analysis consistently reveals that "learning rate" and "location control" are the highest-swing criteria — where 10 hours of research changes the outcome.

What Went Wrong

  • Static document, not an interactive tool. Users must manually copy weights into a spreadsheet. A tiny web app with sliders for weights and instant re-ranking would lower the barrier significantly.
  • Point estimates instead of progression curves. Salary scoring uses single numbers. Year-by-year curves (with promotion probabilities) would capture the time-value of money and long-term trajectory better.
  • Option value not modeled. "Preparing while working" has real option value that static MCDA misses. Real options analysis would quantify the value of keeping paths open.
  • Single-player model. Career decisions often involve a partner/spouse with shared constraints (location, income floor). A two-player version with joint utility would be more realistic.
  • Scores unvalidated. All 15×8 = 120 scores are expert judgment, not calibrated data. Tracking actual outcomes for 50+ people over 3–5 years would ground the model.
