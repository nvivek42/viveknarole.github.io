Goal Clarity Engine

July 2025 3 weeks GitHub Live Demo
Vanilla JS Cloudflare Workers NVIDIA NIM localStorage No Framework Deps

The Problem

High-stakes career decisions (government vs. private sector, stay vs. leave, specialize vs. generalize) are often made with incomplete information, unexamined biases, and time pressure. People default to: following parental expectations, chasing prestige, optimizing for the wrong variable, or freezing in analysis paralysis.

Existing tools are either generic (personality tests), biased (recruiter assessments), or overwhelming (spreadsheets with 50 variables). None force you to articulate trade-offs in your own words, then reflect on them.

Approach

Built a guided interview — not a test — that surfaces your actual priorities, constraints, and mental models through 6 structured stages:

  1. Define the choice — Current situation + genuine options (not fantasy ones)
  2. Know your priorities — Forced ranking (max 3) + hardest trade-off
  3. Picture the work — Day-to-day expectations for each path, corrected in your own words
  4. Consider people & constraints — Practical limits + whose input matters
  5. Test the downsides — Pre-mortem for each direction
  6. Choose a next experiment — Lean + concrete next step (not a final decision)

Technical choices:

  • Vanilla JS + localStorage — No framework, no build step. Draft persists across sessions. Requires JS for interactive features (progress tracker, auto-save, export).
  • Cloudflare Worker + NVIDIA NIM — Optional AI synthesis (opt-in only, explicit consent checkbox, answers never leave browser unless user clicks "Generate")
  • No frontend framework dependencies — No React, no analytics, no CDN for runtime. ~45KB total (HTML + CSS + JS).
  • Progressive enhancement — Core content readable without JS; interactive features and AI synthesis require JS.
Privacy-first: Answers stay in your browser (localStorage). AI synthesis requires explicit checkbox consent. No telemetry, no cookies, no fingerprinting. Worker proxy hides NVIDIA NIM endpoint.

Solution

A single-page interactive worksheet at /portfolio/goal-clarity/ with:

  • 6 stages, 18 prompts (multiple choice + free text)
  • Progress tracker (prompts explored / total)
  • Auto-save to localStorage (survives refresh/close)
  • Export to Markdown (download or print to PDF)
  • Optional AI synthesis via Cloudflare Worker → NVIDIA NIM (Llama 3 / Nemotron)
  • Dark/light mode, responsive, accessible (ARIA labels, focus states, keyboard nav)

The AI synthesis returns: What seems important to you; Tensions and trade-offs; Assumptions to verify; A low-risk next experiment — explicitly labeled as reflection, not advice.

What Went Wrong

  • Claimed "works without JS" but core features need it. The progress tracker, auto-save, and export all require JavaScript. Fixed the copy: "Core content readable without JS; interactive features require JS."
  • Claimed "zero external deps" but uses Cloudflare Worker + NVIDIA NIM. Fixed: "No frontend framework dependencies." The Worker and NIM are backend services, not frontend deps.
  • Single decision template. Only govt vs. private. Users asked for "specialize vs. generalize," "founder vs. employee," "stay vs. move abroad." Template system not built yet.
  • No versioned drafts. localStorage overwrites. Users can't compare earlier vs. later thinking. Snapshots needed.
  • Mobile text input friction. Voice dictation works but UX is rough on small screens. Better textarea handling needed.
